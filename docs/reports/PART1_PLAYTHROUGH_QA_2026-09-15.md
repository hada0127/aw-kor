## 원인과 수정

### 대사 문자와 제어 명령 충돌

1편 파서는 `0x77` 이하를 단일바이트 명령으로 처리한다. 원본의 전각 `Ａ/Ｂ` 대신 ASCII `A/B`를 넣으면 글리프 경로를 벗어난다. `D90854` 메시지의 A/B만 전각으로 바꾼 분리 시험에서 같은 상태·입력의 지도 오염이 사라졌다. 실제 빌드에서는 **텍스트 인코딩 단계**에서 영숫자를 전각화한다. 원시 명령 스트림의 `30/32/33/6B` 같은 제어 바이트는 바꾸지 않는다.

### 합친 문장의 옛 조각 재삽입

`D8FFE3:D9001B` 등은 여러 원본 조각을 한 문장으로 바꾼 범위다. 부모 완성문장에 예전 자식 번역을 연결하고, 재배치 단계에서 다시 원본 조각 경계로 잘라 중복과 잘못된 경계를 만들었다. 해당 완성문장 범위를 명시하고, 재배치는 최종 script writer의 범위를 따른다. 후속 쓰기와 충돌하거나 부분 중첩의 의미가 불확실한 메시지는 재배치에서 제외한다. 삭제된 원본 자식 주소도 중간 포인터 검사에는 보존한다. 문장부호·공백 정규화는 각 텍스트 범위에만 적용한다. 제어 구간이 원본과 다르면 재배치를 제외한다. 정규화 후 텍스트 범위의 폭도 검사하고, 제어 바이트가 섞인 불확실한 범위는 제외한다. 알려진 원본 라인/메시지 시작 주소에 대한 포인터는 ROM 전역에서 검사한다. 임의 바이트 주소에 대한 모든 참조를 입증한 것은 아니다.

편집 시 `D8F377`, `D8FFE3`, `D90050`, `D903CD` 네 범위는 부모 주소의 완성문장을 수정한다. 옛 자식 조각의 개별 번역은 이 네 완성문장에 합치지 않는다. 네 주소는 B팀 보호 번역 밖이며, 다른 B팀 소유 문장이 원문과 다르면 재배치가 현재 바이트를 보존한다.

### 메뉴 전용 글자 목록 누락

`0x0300643C`의 메뉴 글자 검색은 별도 캐시 bank 1을 사용한다. 기존 사전에는 최종 한글 명령 이름의 코드가 없어 글자를 찾지 못했다. `0xD82A1C` 사전의 기존 순서를 보존하고 최종 명령 라벨에 쓰는 한글 코드를 추가한 뒤, `0xB12EE4`의 포인터를 새 사전으로 바꾼다. 특정 화면 위치와 고정 글리프 인덱스를 강제로 쓰던 `0xB19804` 오버레이는 제거했다.

분리 시험에서 대기 한 줄과 공격/대기 두 줄이 모두 정상 표시됐다. 기타 명령 라벨의 실제 표시와 2편 전체는 별도 검수 대상이다.

초반 보병 배정 대사에는 원본의 **두 부대**와 공백을 복원했다. 공격 조건 설명은 “보병은 적 옆이 아니면 공격 못 해”로 수정했고, 병력 수 설명의 문장 사이 공백을 복원했다.

## 리뷰와 판정 한계

Claude·Codex·agy의 읽기 전용 엄격 리뷰를 요청했다. 유효 지적에 따라 후속 writer 충돌 검사, 원본 중간 포인터 보존, 실제 전각 폭 계산, 사전 최종 생성/예약영역 검사, 제어 gap 보존 및 실패 경로 회귀 검사를 보강했다.

사전의 물리 엔트리 수를 캐시 인덱스로 써야 한다는 지적은 실제 로더의 중복 제거 덤프로 반증했다. 원시 명령 스트림 전체에서 ASCII 숫자를 금지하라는 제안은 합법적인 제어 바이트까지 차단하므로 채택하지 않았다. 텍스트 인코더의 렌더러 문맥 전달과 제한된 리터럴 AST 검사를 추가했다. AST 검사는 동적 문자열을 포함한 전 코드 경로의 완전 검증이 아니다. 표시 폭 검사는 텍스트 span 단위이며, 개행 여부가 미확정인 제어 구간을 건너 이어지는 여러 span의 행 합산은 보장하지 않는다. 이런 구간의 공백을 임의로 늘리지 않는다.

agy가 중간 응답에서 쓴 “실기”, “배포 가능” 표현은 이 증거로 뒷받침되지 않아 채택하지 않았으며 정정 리뷰를 요청했다. 실제 증거는 **macOS Apple Silicon의 mGBA 0.10.5 headless**다. 부팅 전 정적 검사도 인게임 시각 검증과 구별한다. 나머지 명령 라벨·후속 임무·2편 전체·실기 및 배포 검증은 미완료로 남긴다.

수집기 재리뷰에서는 명령 응답 대조, stale raw 방지, 종료 오류 보존을 수정·시험했다. 최종 Claude 리뷰의 P1은 0건이다. 남은 P2 제안 5건은 Codex가 별도 판정했다: 로컬 JSON의 적대적 위조 방지, 종료 실패와 캡처 상태 표시 분리, actions의 전원 손실 내구성, Homebrew 이식성, 예외 클래스 통일은 현재 보장 범위의 차단 결함이 아니다. `last_good_checkpoint`를 보존하며, SHA 검사를 인증이나 전원 손실 보장으로 표현하지 않는다.
